## 📥 Встановлення (PWA)

👉 **Швидкий спосіб:** Перейди за посиланням вище та натисни кнопку **«Завантажити застосунок»** на головному екрані.

👉 **Через меню браузера:** Якщо кнопки немає, відкрий меню свого браузера (три крапки або «Поділитися» в Safari) та обери **«Додати на головний екран»** (або «Встановити застосунок»).
